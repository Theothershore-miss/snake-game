# 贪吃蛇小游戏 🐍

基于 Python + pygame 开发的经典贪吃蛇游戏，界面简洁、操作流畅。

## 功能特性

- **方向键控制**：↑ ↓ ← → 控制小蛇移动
- **得分系统**：吃到红色苹果得 10 分，蛇身增长一节
- **最高分记录**：自动保存到本地 `highscore.txt`，重启后保留
- **暂停功能**：空格键暂停/继续
- **游戏结束判定**：撞墙或咬到自身即结束
- **重新开始**：游戏结束后按 R 键重新开始
- **视觉效果**：
  - 黑色背景 + 极淡网格线
  - 圆角蛇身 + 顶部高光/底部阴影的立体感
  - 蛇头眼睛朝向移动方向
  - 苹果造型食物（果体 + 茎 + 叶 + 高光 + 呼吸缩放动画）
  - 圆角半透明得分面板
  - 界面文字带阴影层

## 操作说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 控制蛇的移动方向 |
| 空格 | 开始游戏 / 暂停 / 继续 |
| R | 游戏结束后重新开始 |
| ESC / Q | 退出游戏 |

## 运行方式

### 1. 安装依赖

```bash
pip install pygame
```

### 2. 运行游戏

```bash
python snake_game.py
```

## 技术要点

- **网格坐标系**：逻辑坐标（格子）与像素坐标分离，简化碰撞检测
- **三段式主循环**：事件处理 → 状态更新 → 绘制，职责清晰
- **方向缓冲**：用 `pending_direction` 避免同一帧 180° 掉头
- **按下沿检测**：`当前按下 且 上一帧未按下`，确保一次按键只触发一次
- **预渲染优化**：背景、面板、遮罩只创建一次，每帧直接 blit
